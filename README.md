Pilaniya Farms Website

This repository contains a simple static website scaffold for Pilaniya Farms.

Files added:
- index.html — main landing page
- style.css — basic responsive styles
- script.js — small client-side interactions (mobile nav, contact form simulation)

How to use
1. Serve the files from any static host (GitHub Pages, Netlify, Vercel, your own server).
   - For GitHub Pages: enable Pages in repository settings, select the main branch and root folder.
2. Replace placeholder text, images, and email addresses with real content.
3. Integrate a backend or third-party form provider (Formspree, Netlify Forms, etc.) if you want the contact form to send real messages.
